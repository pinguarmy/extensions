# Browser extensions: support site

Product pages, privacy policies and support for the browser extensions published by pinguarmy. Served with GitHub Pages at https://pinguarmy.github.io/extensions/.

To get help or report a problem, open an issue and put the extension name in the title.

- [TubeNotes: Transcript Export for YouTube](https://pinguarmy.github.io/extensions/tubenotes/) · [privacy](https://pinguarmy.github.io/extensions/tubenotes/privacy.html)
- [CSSPeek](https://pinguarmy.github.io/extensions/csspeek/) · [privacy](https://pinguarmy.github.io/extensions/csspeek/privacy.html). Free experimental beta candidate; not yet available in the store.
- [LiveBlur](https://pinguarmy.github.io/extensions/liveblur/) · [privacy](https://pinguarmy.github.io/extensions/liveblur/privacy.html). Free experimental beta candidate; reversible visual masking, not secure redaction.
