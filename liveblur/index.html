LiveBlur

Free experimental beta. Not yet released. This page describes the beta candidate, not an available installation. No installation link is available yet. Expect limitations and incomplete live-site verification.

Warning: LiveBlur is a reversible visual aid, not a redaction or data-loss prevention tool. Original text remains in the page DOM. The default light blur, and blur in general, may be recoverable. Solid block is also only a visual cover, not deletion or secure redaction. Do not rely on either to protect confidential information.

Review every item before sharing your screen or a screenshot. New or replaced content can be missed. Refreshing or navigating requires you to reopen the extension and apply masks again. Do not share a page if you cannot confirm that it is safe to show.

LiveBlur can visually mask individual elements, selected text within a single text node, or pattern matches in the current page's visible text. The one-time scan looks for email addresses, phone numbers, long digit strings and IBAN-like patterns. Matches are heuristic and can be wrong or incomplete.

Using the beta

Choose light blur, strong blur or solid block. Use Pick Elements to hover and click an element, Blur Selection for selected text, or Scan current content for a single scan. Cross-element text selections are refused. Pick Elements can mask a deliberately chosen form field without changing its value. Esc or the page's Done button stops the picker; closing the popup alone does not. Undo last removes the latest mask, and Unblur All clears the extension's masks and generated text wrappers.

What the scan misses

The scan does not cover iframe contents, Shadow DOM, canvas, CSS-generated text, images, password values or form fields. It is not continuous: new messages, replaced content and pagination require another scan and a fresh manual review. Site rules are not saved, and Remember on this site is not available. Live behavior on some pages remains unverified; a mask count is not evidence that all private information is covered.

Local processing

LiveBlur reads page text and selected elements locally, and temporarily changes the page DOM and styles to display masks. It does not upload or persist page content. Only language, theme and mask-strength preferences are saved in local extension storage. No account, analytics, remote code or network service is used. The privacy policy explains activeTab, scripting and storage permissions and how to delete local preferences.

Privacy policy · Get help or report a problem. GitHub issues are public; do not include confidential page text, screenshots, credentials or other secrets.

如何使用

先选择轻度模糊、强模糊或实色遮挡。使用“选择元素”悬停后点击元素，用“模糊选中文字”处理选区，或用“扫描当前内容”执行一次扫描。跨元素的文字选区会被拒绝。手动选择元素可遮挡你明确选中的表单字段，但不会修改字段值。Esc 或页面上的“完成”按钮会停止选择器，仅关闭弹窗不会停止。“撤销上一步”移除最近的遮挡，“全部取消模糊”清除扩展添加的遮挡和文字包装元素。

扫描范围与遗漏

扫描不覆盖 iframe 内部、Shadow DOM、canvas、CSS 生成的文字、图片、密码值或表单字段。扫描不是持续监控，新消息、替换内容和翻页后都需要重新扫描并逐项检查。站点规则不会保存，“记住此站点”尚不可用。部分页面的真实运行效果尚未验证，遮挡数量不能证明所有私人信息都已覆盖。

本地处理

LiveBlur 在本地读取页面文字和所选元素，临时修改页面 DOM 和样式以显示遮挡，不上传或持久保存页面内容。扩展只在本地存储中保存语言、主题和遮挡强度偏好，不需要账号，不使用统计分析、远程代码或网络服务。隐私政策说明了 activeTab、scripting、storage 的具体用途，以及如何删除本地偏好。
