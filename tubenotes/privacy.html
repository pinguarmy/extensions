TubeNotes Privacy Policy

Last updated: 2026-10-07

TubeNotes does not collect, sell or upload user data. Transcripts are processed on your device and remain there unless you choose to copy or save them. There are no analytics, remote executable code or third-party services.

TubeNotes saves only your interface language, theme, selected export format and timestamp preference in Chrome local extension storage. It does not persist transcripts, watch pages, caption track URLs or credentials.

To read available subtitles, caption and modern transcript API requests run in the current YouTube page context and are sent only to YouTube, using the page's current client context. TubeNotes does not read or store cookies or authorization tokens.

If both data requests fail, TubeNotes may temporarily open YouTube's transcript panel. It closes only panels it opened and restores a description it expanded.

The extension uses the active tab only for its transcript viewing, copying, exporting and timestamp navigation functions. It does not sell data, use data for unrelated purposes or use data to determine creditworthiness or for lending. Removing the extension removes its stored local preferences.

Questions about privacy: open an issue.

TubeNotes 隐私政策

更新日期：2026-10-07

TubeNotes 不收集、不出售，也不上传用户数据。字幕只在你的设备上处理，除非你自己复制或保存，否则不会离开你的设备。扩展没有统计分析，不使用远程代码，也不接入任何第三方服务。

TubeNotes 只在 Chrome 的扩展本地存储里保存四项设置：界面语言、主题、导出格式，以及是否保留时间戳。它不保存字幕、视频页面、字幕地址或任何登录凭据。

为了读取视频已有的字幕，字幕请求和字幕数据请求都在当前 YouTube 页面里发出，只发给 YouTube，用的是这个页面本来的客户端环境。TubeNotes 不读取，也不保存 Cookie 或授权令牌。

如果这两种请求都没拿到字幕，TubeNotes 可能会临时打开 YouTube 的字幕面板。它只关闭自己打开的面板，如果为此展开了视频简介，也会恢复原样。

扩展只在你查看、复制、导出字幕或点击时间戳跳转时使用当前标签页。它不出售数据，不把数据用于与这些功能无关的用途，也不用数据判断信用或用于借贷。卸载扩展会一并删除它保存的本地设置。

有隐私方面的问题，可以在这里提交反馈。
