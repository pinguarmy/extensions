CSSPeek Privacy Policy

Last updated: 2026-11-11

This policy describes CSSPeek's free experimental beta candidate, which has not yet been released.

Page data and copying

CSSPeek reads the current page's DOM and computed styles when you start inspection, including when opening the popup starts it automatically. Processing stays locally in that tab. The extension does not upload or persist page content. It uses no analytics, tracking, remote code or network services.

Copy buttons put selected CSS or outerHTML on your clipboard at your request. HTML can include private page text and attributes. Review it before sharing. If clipboard access is denied, the inspector displays a text field for manual copying. Data you paste into another app or site is then subject to that destination's handling.

Permissions and local preferences

  • activeTab grants temporary access to the current tab after your action, so CSSPeek can inspect that page. No host permissions are requested.
  • scripting injects the bundled local inspector into that tab to read computed styles and display the inspection overlay.
  • storage saves only your language and Start when opened preferences in chrome.storage.local. It does not save inspected page content.

Exit, Esc or navigation removes the inspector. This does not erase anything you have already copied; clear or replace clipboard contents separately if needed. Removing CSSPeek from the browser deletes its stored local preferences.

Privacy questions

Open a support issue. GitHub issues are public and handled by GitHub, outside the extension's local processing. Describe the problem without private page HTML, credentials or other secrets.

CSSPeek 隐私政策

更新日期：2026-11-11

本政策适用于 CSSPeek 的免费实验性 beta 候选版本，产品尚未上线。

页面数据与复制

启动检查后，CSSPeek 会读取当前页面的 DOM 和计算样式。如果设置了打开弹窗时自动启动，打开弹窗也会开始检查。处理在当前标签页本地完成，扩展不上传或持久保存页面内容，不使用统计分析、跟踪、远程代码或网络服务。

只有你点击复制时，扩展才会把所选 CSS 或 outerHTML 放入剪贴板。HTML 可能包含页面的私人文字和属性，分享前请检查。如果剪贴板访问被拒绝，检查器会显示文本框供你手动复制。粘贴到其他应用或网站后的内容，由该接收方处理。

权限、本地偏好与删除

  • activeTab 在你主动操作后授予当前标签页的临时访问权限，用于检查该页面。扩展不申请主机权限。
  • scripting 把随扩展打包的本地检查脚本注入该标签页，用于读取计算样式和显示检查浮层。
  • storage 只在 chrome.storage.local 保存语言和打开时启动的偏好，不保存检查过的页面内容。

点击“退出”、按 Esc 或导航离开会移除检查器，但不会清除已经复制的内容。如有需要，请另行清空或替换剪贴板内容。卸载 CSSPeek 会删除扩展保存的本地偏好。

隐私问题

可以提交支持 issue。GitHub issue 是公开的，由 GitHub 处理，不属于扩展的本地处理流程。请只描述问题，不要提交私人页面 HTML、登录凭据或其他秘密。
