CSSPeek

Free experimental beta. Not yet released. This page describes the beta candidate, not an available installation. No installation link is available yet. Expect limitations and incomplete live-site verification.

Inspect an element by hovering, pin it with a click, and copy a computed CSS rule, computed declarations or its outerHTML. The inspector shows size, a box-model highlight and diagram, grouped computed styles, color swatches and font details.

Using the beta

On a supported website, opening CSSPeek starts inspection by default. Turn off Start when opened in the popup to start with the button instead. Dismiss the popup to reach the page, hover an element and click to pin it. Resume selects another element. Esc or Exit removes the inspector. You can drag, collapse or move the panel to reach covered elements. If clipboard access is denied, select and copy the text manually from the displayed text field.

What a copy does not include

The CSS output is a snapshot of selected computed properties at the current viewport and content, not the original stylesheet. It does not recreate responsive rules, pseudo-elements, CSS variables, animations or every CSS property. Closed shadow roots, frame contents, browser internal pages and protected sites are not supported. Physical hover and panel access on live sites have not been fully verified.

Copied HTML can contain private page content. Review the entire outerHTML before sharing it. Copying CSS or HTML is your choice; clipboard contents may become available to other apps or sites when you paste them.

Local processing

CSSPeek reads the current page's DOM and computed styles when inspection starts, and processes them locally in that tab. It does not upload or persist page content. Only language and Start when opened preferences are saved in local extension storage. No account, analytics, remote code or network service is used. The privacy policy explains activeTab, scripting and storage permissions and how to delete local preferences.

Privacy policy · Get help or report a problem. GitHub issues are public; do not include private page HTML, credentials or other secrets.

如何使用

在支持的网页上打开 CSSPeek，默认立即启动检查。关闭弹窗里的“打开时启动”后，可改为按按钮启动。收起弹窗后，在页面上悬停并点击固定元素。“继续”用于选择其他元素，Esc 或“退出”移除检查器。面板可拖动、折叠或移到另一角，方便选择被挡住的元素。如果剪贴板访问被拒绝，可在显示的文本框中选择文字，手动复制。

复制结果的边界

CSS 输出只是当前窗口尺寸和内容下部分计算样式的快照，不是原始样式表。它不会重建响应式规则、伪元素、CSS 变量、动画或全部 CSS 属性。不支持封闭的 Shadow DOM、框架内页面、浏览器内部页面和受保护站点。真实网站上的物理悬停和面板可达性尚未完全验证。

复制的 HTML 可能包含页面私人内容。 分享前请完整检查 outerHTML。复制 CSS 或 HTML 由你主动触发；粘贴后，其他应用或网站可能获得剪贴板中的内容。

本地处理

启动检查后，CSSPeek 会读取当前页面的 DOM 和计算样式，并在该标签页本地处理，不上传或持久保存页面内容。扩展只在本地存储中保存语言和打开时启动的偏好，不需要账号，不使用统计分析、远程代码或网络服务。隐私政策说明了 activeTab、scripting、storage 的具体用途，以及如何删除本地偏好。
